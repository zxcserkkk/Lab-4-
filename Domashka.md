# Домашнее задание к работе 4
## Условие задачи
Двум командам (A и B) выпали номера. Право первого хода получает та команда, для которой выполняется условие: только один из выпавших номеров четный. Запишите условие для получения права первого хода.

**Вариант 13**

## Алгоритм

1. **Начало**
2. Ввести исходные данные с клавиатуры:
    `a`: номер команды A.
    `b`: номер команды B.
3. Проверить условие: (`a` чётное И `b` нечётное) ИЛИ (`a` нечётное И `b` чётное):
    Если условие выполняется, вывести сообщение, что право первого хода получено.
    Иначе вывести сообщение, что права первого хода нет.
4. **Конец**

##Код

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "Russian");

    /* 1. Ввод номеров */
    int a, b;
    printf("Введите номер команды A: ");
    scanf("%d", &a);
    printf("Введите номер команды B: ");
    scanf("%d", &b);

    /* 2. Проверка условия: только один номер чётный */
    if ((a % 2 == 0 && b % 2 != 0) || (a % 2 != 0 && b % 2 == 0))
    {
        printf("Номера: A = %d, B = %d. Условие выполняется, право первого хода получено.\n", a, b);
    }
    else
    {
        printf("Номера: A = %d, B = %d. Условие не выполняется, права первого хода нет.\n", a, b);
    }

    getchar();  /* считывает оставшийся Enter */
    getchar();  /* ждёт нажатия клавиши */
    return 0;
}
```

## Результат
```
Введите номер команды A: 4
Введите номер команды B: 5
Номера: A = 4, B = 5. Условие выполняется, право первого хода получено.
```
